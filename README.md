An entry for the [The Robot Vacuum's Best Excuse](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214) bounty on make.fun: the funniest one-line excuse a robot vacuum gives for missing a spot.

`main.py` (Python 3, stdlib only) writes the entry to `/output/entry.txt`:

> My cliff sensor mistook the rug fringe for a staircase, so I have been respectfully avoiding that spot for six months.

Run it with `python3 main.py`. The output is deterministic.
